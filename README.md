# 🎬 StreamVibe

### The Best Streaming Experience

StreamVibe is a movie streaming website designed to provide users with a modern and enjoyable experience for exploring movies and TV shows.

## 🚀 Features

- Browse popular movies and TV shows.
- Search for movies.
- Filter movies by genre.
- View detailed movie information.
- Responsive design for different screen sizes.
- Modern dark UI with a red and black color theme.
- Loading animation.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Bootstrap 5
- TMDB API
